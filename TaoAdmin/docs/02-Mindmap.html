TaoAdmin 项目思维导图

微服务权限框架 · .NET 10 + SqlSugar + MySQL + Ant Design Vue · 2026-11（适用版本：2026-11-18 主干）
TaoAdmin微服务后台基础底座
权限模型
认证：账号密码登录 · JWT 令牌 · 刷新令牌 · SVG 图形验证码（默认必填）
登录防护：连错 5 次锁 15 分钟 · 判锁先于密码校验 · 成功即清零
用户管理：增删改查 · 启停 · 重置密码 · 分配角色
角色管理：角色 CRUD · 绑定菜单 · 绑定接口
菜单权限：目录/菜单/按钮三级 · 动态路由 · 显隐控制
接口权限：权限码登记 · 前端按钮显隐 + 后端二次校验
前端（Vue3 + Ant Design Vue）
MVVM：组合式 API · 响应式绑定
动态路由：登录后按菜单树生成
公用组件：FilterBar 筛选栏（一行 + 展开）
页面：工作台 · 用户/角色/菜单/接口 · 任务 · 监控 · 日志 · 登录安全 · 审计日志 · 通知渠道
v-permission 指令：按钮级权限
后端分层（DDD）
Domain 领域层：实体 + 仓储接口 + 领域异常
Application 应用层：应用服务 + DTO（对齐前端契约）
Infrastructure 基础设施：SqlSugar 仓储 + CodeFirst 初始化
IdentityService 5001：权限服务（瘦控制器）
TaskService 5002：Quartz 定时任务服务
GatewayService 5000：YARP 网关 · 鉴权 · 限流 · 熔断 · TraceId
多租户与工作流
多租户：租户管理 · ITenantEntity 自动过滤 · 平台公共数据(TenantId=0)全租户可见
租户上下文：JWT tenant_id 声明 · X-Tenant-Id 覆盖 · 总开关可关闭
工作流：线性审批流模板（JSON 节点）· 发起 → 逐级审批 → 通过/驳回
待办任务：按角色查看 · 租户隔离 · 超管跨租户审批
演示数据：华东/华南双租户 · 请假(两级)/报销(一级)模板 · 全状态实例
消息队列与网关防护
消息队列：IMessageQueue 抽象 · 内存实现（默认）/ RabbitMQ 双实现一键切换
订阅泵：启动时自动注册 IMessageHandler 常驻消费 · 单条失败不中断
内置示例：user.created 欢迎消息 · demo.test 演示落库
接口幂等：Idempotency-Key 防重 · 重放返回原响应 · TTL 600s
网关限流：固定窗口 100 次/10s · 用户/IP 分桶 · 超限 429
网关熔断：连续 5 次失败熔断 · 快速失败 503 · 冷却 30s 半开恢复
接口文档：三个服务均内置 Swagger（/swagger）· 中文标题描述
操作日志：写操作 + 登录审计（成败均记账号）· IP/耗时/TraceId · 异步落库
数据字典：类型/明细维护 · 按编码取下拉明细 · 内置性别/状态种子 · 租户隔离
防护审计
验证码：SVG 输出 · 4 位去 0O1lI · 一次性消费 · 5 分钟有效 · 开关/阈值可配
登录安全页：五项配置存 sys_site_config · 保存即生效不重启
审计日志页：类别/账号/结果/时间筛选 · 管理操作自动留痕（AuditTrail）
日志保留：默认 90 天（0=永久）· 手动清理返回删除数
通知渠道页：SMTP/短信配置留存 · 发送通道占位（只埋不接线）
文件中心（基础框架内置）
接口：/api/identity/files/** · 上传/分页/删除需 sys:file:manage · 下载登录即可（无令牌 401）
上传：MD5 秒传去重（deduplicated）· 16 种扩展名白名单 · 5MB 上限
下载：仅 /uploads 前缀路径 · 原文件名交付 · 记录不存在 404
删除：软删 + 物理删 · 删后原路径 404
存储切换：FileStorage:Provider = local（默认）/ minio（S3 兼容，数据不出内网）· 业务零改动
文件中心（独立解决方案 TaoFiles）
独立部署：TaoFiles 单独运行，业务系统零耦合集成
上传：MD5 去重/秒传 · 扩展名白名单 · 大小限制 · 雪花 ID 重命名
业务集成：只存返回的相对路径，拼服务地址即可访问
管理页面：上传/搜索/缩略图/复制路径/删除，开箱即用
存储抽象：本地磁盘实现（可换 MinIO/OSS）· 可选 API Key
基础设施
MySQL 8：业务数据 · CodeFirst 自动迁移 · 主从读写分离
Redis 7：缓存 · 心跳 · 刷新令牌
Nacos v2（可选）：注册中心 + 配置中心
Elasticsearch（可选）：分布式日志存储
可观测性
服务监控中心：健康状态 · 实例数 · 版本
日志中心：级别/服务/关键字/TraceId 检索 · 堆栈详情
TraceId 全链路贯穿（网关生成透传）
本地文件日志 + ES 双写（可选）
定时任务（Quartz）
任务 CRUD：Cron 表达式 · 处理器 · 参数
任务控制：立即执行 · 暂停 · 恢复 · 删除
示例任务 heartbeatJob：每 30s 写 Redis 心跳
工程化
TaoAdmin.Utilities 公用工具库（加解密/JSON/HTTP/树…）
部署：Docker Compose · Jenkins · GitHub Actions · K8s
单元测试：xUnit（雪花 ID 唯一性等）
文档：需求 · 架构图 · 操作手册 · 运维教程
