# TaoAdmin 需求文档

> 版本：v1.2 ｜ 更新日期：2026-11-19 ｜ 适用版本：2026-11-18 主干 ｜ 适用范围：TaoAdmin 微服务权限框架

---

## 1. 项目背景与目标

企业内部多个业务系统都需要「账号、角色、权限、菜单、日志、定时任务」等基础能力。
重复开发这些能力成本高、口径不一。TaoAdmin 作为**微服务后台基础底座**，一次建设，多项目复用。

**核心目标**

| 目标 | 说明 |
|---|---|
| 统一权限 | 用户/角色/菜单/接口四级权限模型，前端控制显隐、后端控制访问，双防线 |
| 微服务架构 | 服务按业务拆分，网关统一入口，可独立部署、独立扩容 |
| 开箱即用 | 首次启动自动建库建表、种子数据到位，登录即可用 |
| 可观测 | 请求日志集中查询、TraceId 全链路贯穿、服务健康状态可视化 |
| 可复用 | 公用工具库（加解密/JSON/HTTP/树结构等）沉淀，业务项目直接引用 |

## 2. 用户与角色

| 使用者 | 关注点 |
|---|---|
| 系统管理员 | 管理账号、分配角色权限、维护菜单与接口资源 |
| 运维人员 | 查看服务健康状态、查日志定位问题、管理定时任务 |
| 二次开发人员 | 以本框架为底座开发业务模块，复用权限/日志/任务能力 |
| 普通用户 | 登录系统使用被授权的功能 |

## 3. 功能需求

### 3.1 认证与用户管理（FR-100）
- FR-101 账号密码登录，JWT 令牌（默认 120 分钟），支持刷新令牌（7 天）
- FR-102 登录返回用户信息、权限码集合、菜单树，前端据此生成动态路由
- FR-103 用户分页查询（按用户名、状态筛选）、新增、编辑、删除、启用/禁用
- FR-104 重置密码、为用户分配角色

### 3.2 角色与权限（FR-200）
- FR-201 角色增删改查（如：超级管理员、普通用户）
- FR-202 角色-菜单绑定：决定侧边栏显示哪些菜单（菜单权限）
- FR-203 角色-接口绑定：按钮级权限码（如 `sys:user:add`）控制前端按钮显隐；
  同名权限码在后端接口上二次校验，越权请求直接拒绝（接口权限）

### 3.3 菜单与接口资源（FR-300）
- FR-301 菜单树管理：目录/菜单/按钮三种类型，支持显隐（Visible）配置
- FR-302 前端路由由后端菜单树动态生成，新增菜单无需改前端代码
- FR-303 接口资源登记：路径 + HTTP 方法 + 权限码，作为接口权限的数据源

### 3.4 系统监控（FR-400）
- FR-401 服务健康总览：网关/权限/任务三个服务的存活状态、实例数、最近检查时间
- FR-402 日志中心：按时间范围、级别（DEBUG~FATAL）、服务名、关键字/TraceId 检索
- FR-403 日志详情：完整消息、异常堆栈、TraceId；支持自动刷新

### 3.5 定时任务（FR-500）
- FR-501 任务 CRUD：任务名、分组、Cron 表达式、处理器、参数
- FR-502 任务控制：立即执行一次、暂停、恢复、删除
- FR-503 内置示例任务 heartbeatJob：每 30 秒向 Redis 写服务心跳

### 3.6 系统首页（FR-600）
- FR-601 工作台总览：注册用户数、在线服务数、定时任务数、今日日志数
- FR-602 服务状态卡片、运行中任务一览、最近错误日志

### 3.6 数据库读写分离（FR-700）
- FR-701 应用层支持主从读写分离：写入与事务固定走主库，普通查询按从库自动分流
- FR-702 从库通过配置文件声明（支持多从库），总开关一键启停，默认关闭、单库零改造运行
- FR-703 提供 ForceMaster 机制：写后立即读等强一致性场景可临时固定走主库
- FR-704 配套数据库一键初始化脚本（建库建表+种子数据）与主从复制搭建说明

### 3.7 消息队列（FR-800）
- FR-801 统一消息队列抽象（IMessageQueue）：内置内存实现（本地/单机零依赖）与 RabbitMQ 实现（`RabbitMq:Enabled=true` 一键切换，支持持久化与断线重连）
- FR-802 业务代码只面向主题收发消息（MessageEnvelope：Topic + Body + 消息 ID），不感知底层提供方
- FR-803 后台订阅泵：服务启动时自动把所有 `IMessageHandler` 注册到对应主题常驻消费，单条消息处理异常不中断队列
- FR-804 内置两个示例：`user.created`（新用户自动生成欢迎站内消息）、`demo.test`（演示消息落库），并在消息中心可查
- FR-805 提供消息队列状态查询接口（当前提供方、堆积情况）与演示发布接口

### 3.8 多租户（FR-900）
- FR-901 租户管理：租户增删改查、启用/停用，租户编码唯一
- FR-902 数据隔离：实现 ITenantEntity 的业务表自动按租户过滤（查询隔离 + 写入自动补租户 ID）
- FR-903 约定 TenantId=0 为平台层公共数据，全租户可见；超级管理员（平台账号）跨租户查看与审批
- FR-904 租户上下文由网关侧 JWT 声明 `tenant_id` 解析（支持 `X-Tenant-Id` 请求头覆盖，便于超管代操作）
- FR-905 多租户总开关（MultiTenant:Enabled），单租户项目可关闭、零改造运行

### 3.9 工作流引擎（FR-1000）
- FR-1001 线性审批流：流程模板（JSON 节点定义）→ 发起实例 → 逐节点审批 → 通过/驳回
- FR-1002 节点按角色审批（approverRole），驳回即终止流程，最后一级通过自动完结
- FR-1003 我的待办：审批人按角色查看待办任务（叠加租户隔离）；超管可跨租户审批
- FR-1004 流程实例分页（我的/全部）、实例详情（含任务历史与审批意见）
- FR-1005 内置模板与模拟数据：请假审批（两级）、报销审批（一级），覆盖待审批/已通过/已驳回等状态

### 3.10 网关限流（FR-1100）
- FR-1101 网关统一固定窗口限流（默认 100 次/10 秒，可配置）
- FR-1102 已登录用户按用户 ID 分桶，未登录请求按客户端 IP 分桶，互不挤占
- FR-1103 触发限流返回 429 与中文提示，超时窗口自动恢复

### 3.11 网关熔断（FR-1200）
- FR-1201 熔断按路由前缀（identity/job/monitor）独立统计：连续 5 次失败（5xx/连接失败）触发熔断
- FR-1202 熔断期间请求直接快速失败（503 中文提示），不再打向故障服务；冷却 30 秒后半开试探恢复
- FR-1203 阈值与冷却时间均可通过网关配置调整

### 3.12 接口幂等（FR-1300）
- FR-1301 请求头 `Idempotency-Key` 防重：同一键重放直接返回首次响应（响应头 `X-Idempotent-Replayed: true`），不重复执行业务
- FR-1302 幂等键 = 租户 + 用户 + 路径 + 键，默认有效期 600 秒，内存存储（多实例部署可替换为 Redis）
- FR-1303 以 `[Idempotent]` 特性标注需要防重的接口，例如发起审批、消息发布

### 3.13 接口文档 Swagger（FR-1400）
- FR-1401 三个服务均内置 Swagger/OpenAPI 文档页（/swagger），中文标题与描述
- FR-1402 网关文档页说明各服务文档入口；生产环境可按需关闭

### 3.14 操作日志（FR-1500）
- FR-1501 记录所有写操作（POST/PUT/DELETE）与登录请求（成功/失败均记录），含方法、路径、HTTP 状态、业务成败、IP、耗时、TraceId
- FR-1502 登录审计记录尝试的账号（便于发现暴力破解），密码等敏感字段绝不入库
- FR-1503 日志异步落库不阻塞请求，审计失败不影响业务；分页查询接口支持按类别/账号/时间范围筛选

### 3.15 数据字典（FR-1600）
- FR-1601 字典类型与明细的维护接口（新增/编辑/删除，软删除）
- FR-1602 按编码取启用明细接口 `/dict/items/{dictCode}`，供前端下拉框/状态转义直接使用
- FR-1603 内置种子：性别、通用状态、审批实例状态；字典支持租户隔离（平台公共字典全租户可用）
- FR-1604 字典编码唯一校验

### 3.16 文件中心（FR-1700，独立解决方案 TaoFiles）
- FR-1701 文件管理作为独立解决方案（TaoFiles）单独部署，与基础框架解耦，可被任意业务系统集成
- FR-1702 统一上传接口（multipart）：扩展名白名单 + 大小限制校验，文件名以雪花 ID 重命名（不信任用户输入）
- FR-1703 相同内容（MD5 一致）重复上传直接复用已有记录与物理文件（秒传），不占额外空间
- FR-1704 上传返回相对路径（如 /uploads/2026/10/xxx.png），业务系统只保存相对路径，拼接服务地址即可访问
- FR-1705 双入口管理：基础框架后台内置「文件管理」菜单页（接口调用文件中心，服务地址可配），文件中心亦自带独立管理页面；均支持上传、搜索、分页、图片缩略图预览、一键复制相对路径、删除
- FR-1706 存储抽象 IFileStorageProvider：默认本地磁盘实现（按年/月分目录），可替换为 MinIO/OSS 而业务零改动
- FR-1707 可选 API Key 认证（配置 TaoFiles:ApiKey 后所有接口要求 X-Api-Key）；自带 Swagger 文档与健康检查

### 3.17 防护审计（FR-1800）
- FR-1801 登录图形验证码：SVG 输出无第三方依赖，`GET /api/identity/audit/captcha` 匿名获取；
  答案 4 位去易混淆字符（去 0O1lI），一次性消费（校验即删，对错同删），有效期 5 分钟
- FR-1802 验证码开关与触发阈值可配（sys_site_config：`loginCaptchaRequired` / `captchaAfterFails`）；
  未配置时默认每次登录都要验证码（loginCaptchaRequired 默认 true）
- FR-1803 登录失败锁定：窗口内连续失败达 `loginMaxFails`（默认 5 次）锁定 `loginLockMinutes`（默认 15 分钟），
  锁定中拒绝登录并提示剩余分钟（HTTP 423），不计新失败；密码正确即清零，到期自动解锁
- FR-1804 登录安全链路顺序：判锁先于密码校验（防继续撞库）→ 验证码按设置消费 → 密码校验（失败记账、达阈值锁定）→ 成功清零解锁；
  验证码错误不进锁定账（防恶意灌账本）
- FR-1805 登录安全设置页（系统管理 → 登录安全，`sys:audit:manage` 权限）：五项配置读写 sys_site_config，
  保存即清缓存立即生效不重启；边界值当场校验（失败次数 1~99、锁定 1~1440 分钟、验证码阈值 0~99、日志保留 0~3650 天）
- FR-1806 审计日志页（系统管理 → 审计日志，`sys:audit:manage` 权限）：按类别/账号/结果/时间区间分页筛选；
  登录安全设置与通知渠道保存等管理操作自动写入审计留痕（AuditTrail）
- FR-1807 日志保留策略：`logRetentionDays`（默认 90 天，0=永久）；`POST /api/identity/audit/cleanup`
  立即执行一轮清理，返回删除条数
- FR-1808 通知渠道页（系统管理 → 通知渠道，`sys:audit:manage` 权限）：SMTP/短信网关配置读写存
  sys_site_config，保存即生效落库；发送通道为占位实现（只埋不接线，不发真实请求）

### 3.18 内置文件中心（FR-1900，基础框架内）
- FR-1901 文件能力内置于权限服务（`/api/identity/files/**`，经网关 `/api/identity` 前缀转发），
  落库 sys_file 表（CodeFirst 自动建表），与独立解决方案 TaoFiles（FR-1700）互不依赖
- FR-1902 上传（multipart，字段 `file`）：扩展名白名单 16 种（png/jpg/jpeg/gif/webp/pdf/txt/md/csv/xlsx/xls/docx/doc/zip/mp3/mp4），
  单文件上限 5MB，超限或白名单外类型直接拒绝（400）
- FR-1903 同内容秒传：上传前先算 MD5，命中同 MD5 未删记录直接复用（不落新文件、不重复占存储），
  返回 `deduplicated: true`
- FR-1904 权限口径：上传/分页/删除要求 `sys:file:manage` 权限（超管角色直接放行）；下载登录即可（无令牌 401），
  业务侧按返回的相对路径交付文件
- FR-1905 下载：`GET /api/identity/files/download?url=相对路径`，仅接受 `/uploads` 前缀路径（防路径穿越），
  文件名使用登记的原文件名；文件或记录不存在返回 404
- FR-1906 删除：`DELETE /api/identity/files/{id}`，软删记录 + 删物理文件（秒传复用场景物理文件可能已不存在，容忍）；
  删除后原路径下载返回 404
- FR-1907 存储切换（FileStorage:Provider）：local（默认，本地盘 `FileStorage:Root`）| minio（S3 兼容对象存储），
  业务代码经 IFileStorageProvider 抽象零改动；对象键与本地盘同构（`/uploads/{yyyy}/{MM}/{GUID}{ext}`）
- FR-1908 MinIO 部署口径：Endpoint 指向内网对象存储（AWS Signature V4 签名，数据不出内网），
  禁止配置公有云 OSS

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 列表接口分页返回；常规查询响应 < 500ms（局域网）；读多写少场景通过读写分离水平扩展读能力 |
| 安全 | JWT 验签在网关统一完成；接口级权限二次校验；密码不明文存储；网关限流与熔断保护后端服务；登录验证码与失败锁定防护撞库 |
| 可用性 | 服务无状态可水平扩展（雪花 ID 机器号区分）；网关挂了前端不可用，业务服务挂单个实例不影响整体；熔断防止故障扩散 |
| 可维护 | DDD 分层清晰；日志分级输出，本地文件 + ES 双写可选 |
| 兼容 | Chrome/Edge 现代浏览器；后端 .NET 10 |
| 数据 | 雪花 ID 全局唯一；CodeFirst 迁移；种子数据幂等（逐项判断，可重复启动） |

## 5. 边界与约束

- 单组织维度项目可直接关闭多租户开关运行；多租户为接口级过滤，暂不含分库分表
- 消息队列默认内存实现，仅适用于单实例部署；多实例/生产环境切换 RabbitMQ
- 工作流为线性审批流引擎，不含会签、加签、条件分支等复杂流程
- 接口幂等为内存实现，多实例部署建议替换为 Redis 存储
- Nacos / ES 为可选组件，本地开发可不启用
- 默认账号 admin / Admin@123，上线前必须改密
