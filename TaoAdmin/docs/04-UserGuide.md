# TaoAdmin 操作手册

> 面向系统管理员与日常使用者，说明系统各功能的操作方法。
> 部署安装请看《05-DevOpsGuide.md》。
> 适用版本：2026-11-18 主干 ｜ 更新日期：2026-11-19

---

## 1. 登录系统

1. 浏览器打开系统地址（本地开发 `http://localhost:5173`，线上以实际域名为准）；
2. 输入账号密码，默认超级管理员账号 `admin / Admin@123`（**上线后请立即修改**）；
3. 按提示输入图形验证码（默认每次登录都要；验证码点图可刷新，输错或过期后请刷新重取）；
4. 登录成功后进入工作台首页。

> 验证码与锁定：连续输错密码达阈值（默认 5 次）账号锁定 15 分钟，锁定期内登录会提示剩余分钟；
> 验证码错误不占用失败次数。阈值与开关由管理员在「登录安全」页调整（见第 11 节）。

> 忘记密码：请其他管理员在「用户管理 → 重置密码」里重置；唯一管理员丢失密码时，需运维直接更新数据库 `sys_user` 表的密码字段（BCrypt 加密）。

## 2. 工作台首页

进入系统后的总览页面：

- **顶部统计卡**：注册用户数、在线服务数、定时任务数、今日日志数；
- **服务状态**：网关、权限服务、任务服务的健康状态（绿色为正常）；
- **运行中任务**：正在调度的定时任务及下次执行时间；
- **最近错误日志**：快速发现异常。

## 3. 用户管理

路径：系统管理 → 用户管理

| 操作 | 说明 |
|---|---|
| 查询 | 顶部筛选栏：用户名可直接输入；点「展开」还有状态筛选；点「查询」生效，「重置」清空条件 |
| 新增用户 | 点「+ 新增用户」，填写用户名（登录账号，唯一）、昵称、初始密码、邮箱、手机号、状态 |
| 编辑 | 修改昵称、邮箱、手机号、状态；用户名不可改 |
| 分配角色 | 打开「分配角色」抽屉，勾选角色后保存；角色决定该用户能看到哪些菜单和按钮 |
| 重置密码 | 为该用户设置新密码 |
| 删除 | 二次确认后删除，不可恢复 |

## 4. 角色管理

路径：系统管理 → 角色管理

- **新增/编辑角色**：角色名称（中文，如"运营专员"）、角色编码（英文，如 `ops`，创建后不可改）、描述；
- **分配权限**：为角色绑定两样东西：
  - **菜单**：勾选后该角色用户登录可见对应菜单；
  - **接口**：勾选后该角色用户才能调用对应接口（按钮里的操作才可用）。
- 内置角色：`超级管理员（admin）` 拥有全部权限；`普通用户（common）` 仅基础查看权限。

## 5. 菜单管理

路径：系统管理 → 菜单管理（树形展示）

- **菜单类型**：
  - 目录：侧边栏分组（如"系统管理"），不对应页面；
  - 菜单：对应一个页面，需填组件路径（如 `system/user/index`）；
  - 按钮：挂在菜单下，配权限码（如 `sys:user:add`），用于控制页面按钮。
- **可见（Visible）**：关闭后菜单不出现在侧边栏，但仍可通过 URL 访问（适合"隐藏但可用"的页面）。
- 改动菜单后，用户重新登录或刷新页面即可看到新菜单。

## 6. 接口管理

路径：系统管理 → 接口管理

登记后端接口资源：接口名称、请求方法（GET/POST/...）、路径、权限码、状态。
这些登记项是「角色-接口」授权的数据来源；接口默认启用，禁用后调用会被拒绝。

## 7. 定时任务

路径：任务中心 → 定时任务

| 操作 | 说明 |
|---|---|
| 新增任务 | 任务名称、分组、Cron 表达式（如 `0/30 * * * * ?` 每 30 秒）、处理器（程序内实现的 Job 名）、参数、描述 |
| 执行一次 | 不等调度周期，立即运行一次 |
| 暂停 / 恢复 | 暂停后不再调度，可随时恢复 |
| 编辑 / 删除 | 修改任务定义 / 移除任务 |

> Cron 为 Quartz 6 位格式（秒 分 时 日 月 周）。示例任务 heartbeatJob 每 30 秒向 Redis 写服务心跳，供服务监控判断存活。

## 8. 服务管理中心

路径：系统监控 → 服务管理中心

展示每个服务：健康状态、实例数、健康检查时间、版本、实例明细。
全部绿色表示系统正常；某服务变红时先看它的实例明细，再到日志中心排查。

## 9. 日志管理中心

路径：系统监控 → 日志管理中心

- **筛选**：时间范围 + 级别为核心条件（默认显示）；点「展开」出现服务名、关键字（支持 TraceId）；
- **查询**：列表展示时间、级别（INFO/WARN/ERROR 着色）、服务、TraceId、消息摘要；
- **详情**：点击任意一行，查看完整消息与异常堆栈；
- **自动刷新**：排查问题时可开启，每 10 秒自动拉取最新日志。

> 排障小技巧：从报错接口的响应头或网关日志里拿到 TraceId，到日志中心搜索该 TraceId，可串起整条调用链。

## 10. 通用操作约定

- 列表页统一分页，底部显示总条数、每页条数切换（10/20/50/100）、输入页码直接跳转；
- 危险操作（删除）均有二次确认；
- 无权限的按钮自动隐藏，强行调用接口也会被服务端拒绝；
- 登录过期（默认 2 小时）后重新登录即可。

## 11. 登录安全

路径：系统管理 → 登录安全（需 `sys:audit:manage` 权限）

维护登录防护与日志保留策略，保存即生效、无需重启服务：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 连续失败锁定次数 | 5 次 | 同一账号窗口内连续失败达该次数即锁定（1~99） |
| 锁定时长 | 15 分钟 | 到期自动解锁；密码正确立即清零（1~1440 分钟） |
| 登录验证码开关 | 开启 | 开启后登录需要图形验证码 |
| 验证码触发阈值 | 0 | 0=每次登录都要验证码；N=连续失败达 N 次后才要求验证码（0~99） |
| 日志保留天数 | 90 天 | 审计日志保留策略，0=永久保留（0~3650） |

> 边界值当场校验，防止管理员手滑锁死全站（如失败次数最低 1 次、锁定时长最低 1 分钟）。

## 12. 审计日志

路径：系统管理 → 审计日志（需 `sys:audit:manage` 权限）

- **筛选**：类别、账号、成功/失败、时间区间，分页展示；
- **留痕范围**：登录安全设置保存、通知渠道保存等管理操作自动写入审计（谁改的、改前改后值）；
- **日志清理**：点「立即清理」执行一轮保留策略外的旧日志批量删除，返回删除条数；
  也可调 `POST /api/identity/audit/cleanup`；
- 配套接口：`GET/PUT /api/identity/audit/settings`（读取/保存设置）、`GET /api/identity/audit/log`（分页查询）。

## 13. 通知渠道

路径：系统管理 → 通知渠道（需 `sys:audit:manage` 权限）

- 维护 SMTP/短信网关等通知配置，整体覆盖保存，落库即留存；
- **发送通道为占位实现（只埋不接线）**：配置保存成功即生效落库，但不发真实邮件/短信；
  后续接线后无需改配置结构；
- 配套接口：`GET /api/identity/notify-channel`、`PUT /api/identity/notify-channel`。

以下能力当前以接口形式提供（前端页面规划中，可直接用 API 工具按下方示例调用）：

## 14. 多租户管理（接口）

路径前缀：`/api/identity/tenants`（需管理员权限）

| 操作 | 接口 | 说明 |
|---|---|---|
| 租户列表 | GET `/tenants` | 超管可看全部租户 |
| 新增 / 编辑 / 删除 | POST `/tenants` 等 | 租户编码唯一，支持启用/停用 |

- 租户用户登录后，可见范围 = **平台公共数据（TenantId=0）+ 本租户数据**，其余租户数据完全不可见；
- 超级管理员（平台账号）默认跨租户可见全部数据；
- 请求头 `X-Tenant-Id` 可覆盖租户上下文（仅超管使用，便于代租户操作）。

## 15. 工作流审批（接口）

路径前缀：`/api/identity/workflow`

一次完整的两级审批演示（用内置演示账号即可跑通）：

1. **east01 登录**，发起审批：
   `POST /workflow/instances`，请求头带 `Idempotency-Key: demo-001`（防重复提交），
   请求体 `{"workflowCode":"leave_audit","bizTitle":"张员工的婚假申请"}`；
2. **east_leader 登录**，查看待办 `GET /workflow/tasks`，对第一级「组长审批」任务：
   `POST /workflow/tasks/{taskId}/approve`，请求体 `{"approved":true,"comment":"同意"}`；
3. 系统自动流转到第二级「经理审批」；**admin**（超管，可跨租户）或本租户经理角色继续审批；
4. 最后一级通过后实例状态变为**已通过**；任意一级驳回则整个流程**终止**。

内置模板：`leave_audit` 请假审批（组长 → 经理两级）、`expense_audit` 报销审批（经理一级）。
种子数据覆盖：待组长审批、待经理审批、已通过、已驳回。

> 发起审批接口带 `[Idempotent]` 特性：同一个 `Idempotency-Key` 重复提交会直接返回首次结果（响应头 `X-Idempotent-Replayed: true`），不会重复建单。

## 16. 消息中心与消息队列

- **消息中心页面**（已上线）展示站内消息，支持已读/未读；
- **消息队列**（接口 `/api/identity/messages/*`）当前为后台能力：
  - `GET /messages/demo/stats` 查看当前提供方（memory / rabbitmq）与队列状态；
  - `POST /messages/demo/publish`（带 `Idempotency-Key`，请求体 `{"topic":"demo.test","content":"..."}`）演示发布；
  - 内置消费者：`demo.test` → 演示消息落库；`user.created` → 新用户自动收到欢迎消息。
- 本地默认内存实现零依赖；生产切 RabbitMQ 见运维教程。

## 17. 网关限流与熔断（自动生效）

这两项为网关内置保护能力，无需人工操作，异常时的现象如下：

| 现象 | 含义 | 处理 |
|---|---|---|
| HTTP 429「请求太频繁」 | 触发限流（默认同一用户/IP 每 10 秒 100 次） | 稍等片刻（≤10 秒）自动恢复 |
| HTTP 503「服务熔断中」 | 目标服务连续 5 次失败被熔断保护 | 先恢复目标服务，约 30 秒后自动恢复转发 |

阈值均可调，见《05-DevOpsGuide.md》。

## 19. 操作日志（接口）

路径前缀：`/api/identity/operation-logs`（需 `sys:log:query` 权限）

- 记录范围：所有写操作（增删改）+ 登录请求；**登录失败也记录尝试的账号**，便于发现暴力破解；
- 密码等敏感字段绝不入库，只记方法、路径、状态、IP、耗时、TraceId；
- 查询参数：`category`（login=登录 / operation=操作）、`userName`、`begin`/`end` 时间范围；
- 可与日志中心的 TraceId 联动：操作日志里的 TraceId 可直接去日志中心搜出完整调用链。

## 20. 数据字典（接口）

路径前缀：`/api/identity/dict`

- 管理接口（需 `sys:dict:manage` 权限）：`GET/POST/PUT/DELETE /dict/types`、`/dict/data`，编码唯一；
- 下拉数据源（登录即可）：`GET /dict/items/{dictCode}`，返回按 sort 排序的启用明细，前端直接用 `label/value` 渲染下拉框；
- 内置种子：性别（gender：男M/女F/未知U）、通用状态（status：启用1/禁用0）、审批实例状态（workflow_status）；
- 字典按租户隔离：平台公共字典全租户可用，租户可建自己的私有字典。

## 21. 文件中心（基础框架内置，接口）

路径前缀：`/api/identity/files`（经网关转发；上传/分页/删除需 `sys:file:manage` 权限，下载登录即可）

| 操作 | 接口 | 说明 |
|---|---|---|
| 上传 | POST `/files/upload`（multipart，字段 `file`） | 扩展名白名单 16 种（png/jpg/jpeg/gif/webp/pdf/txt/md/csv/xlsx/xls/docx/doc/zip/mp3/mp4），单文件上限 5MB |
| 分页查询 | GET `/files?pageIndex=1&pageSize=10&keyword=` | 按原文件名模糊搜索，返回 sys_file 记录 |
| 下载 | GET `/files/download?url=相对路径` | 仅接受 `/uploads` 前缀路径；文件名用登记的原文件名；无令牌 401、记录不存在 404 |
| 删除 | DELETE `/files/{id}` | 软删记录 + 删物理文件；删除后原路径下载返回 404 |

- **同内容秒传**：上传前先算 MD5，命中同 MD5 未删记录直接复用（不落新文件、不重复占存储），返回 `deduplicated: true`；
- **业务系统集成**：业务表只保存返回的 `fileUrl` 相对路径（如 `/uploads/2026/11/xxx.png`），展示/下载经本接口交付；
- **存储切换**：默认本地磁盘（`FileStorage:Root`）；配置 `FileStorage:Provider=minio` 切换到内网 MinIO 对象存储，
  业务零改动（配置见《05-DevOpsGuide.md》第 15 节）。

## 22. 文件中心（独立解决方案 TaoFiles）

文件管理不占用基础框架，单独解决方案部署（默认 http://localhost:5003 ）：

- **后台管理菜单（推荐日常使用）**：登录后台后，侧边栏「文件管理」菜单即可上传、搜索、预览、复制相对路径、删除——页面在基础框架里，数据通过接口调用文件中心服务；页面右上角可配置文件中心服务地址（默认 http://localhost:5003 ，存本机）。要求文件中心允许跨域（默认已开启）；
- **独立管理页面**：浏览器打开文件中心根路径，功能相同，适合不登录后台直接管理；
- **秒传复用**：相同内容的文件重复上传自动命中复用（不占额外空间），返回 `reused: true`；
- **业务系统集成**：调 `POST /api/files/upload`（multipart，字段 file），把返回的 `fileUrl`（相对路径）存进业务表即可；展示时拼上文件中心地址，如 `http://localhost:5003` + `/uploads/2026/10/xxx.png`；
- **安全**：扩展名白名单 + 50MB 大小限制；可选 API Key（配置后所有接口要求 `X-Api-Key` 请求头）；
- 集成示例与配置说明见 TaoFiles 目录内 README。
