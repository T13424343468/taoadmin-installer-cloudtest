TaoAdmin 项目架构图

自上而下：客户端 → 网关 → 服务（DDD 分层）→ 中间件；右侧为可观测性与部署形态 ｜ 适用版本：2026-11-18 主干 · 2026-11-19
① 客户端层 浏览器访问
管理后台前端（Vue3 + Ant Design Vue）验证码登录 · 动态路由 · 用户/角色/菜单/接口管理 · 定时任务 · 监控 · 日志中心 · 登录安全 · 审计日志 · 通知渠道
其它接入方第三方系统可走网关 OpenAPI（携带 JWT）
▼ HTTPS ▼
② 接入层 统一入口
Nginx / 负载均衡托管前端静态文件 · /api 反代 · SPA 回退 :80/:443
TaoAdmin 网关（YARP）JWT 验签 · 限流（100次/10s · 用户/IP 分桶）· 熔断（连续5次失败 → 503 快速失败）· 跨域 · 路由转发 · TraceId 生成 :5000
/api/identity/** → 权限服务（含 /files/** 文件中心、/audit/** 防护审计）
/api/job/** → 任务服务
/api/monitor/** → 监控接口（权限服务内）
▼ 转发 ▼
③ 业务服务层（DDD 分层，可水平扩展）
IdentityService 权限服务 :5001验证码/锁定防护登录 · 用户/角色/菜单/接口 CRUD · 多租户管理 · 工作流审批 · 消息队列 · 服务监控 · 日志查询 · 防护审计（验证码/登录安全/审计日志/通知渠道） · 内置文件中心（/files 上传秒传/下载/删除）
TaskService 任务服务 :5002Quartz 调度 · 任务 CRUD · 暂停/恢复/执行 · Redis 心跳
Domain 领域层SysUser/SysRole/SysMenu/SysApi/SysJob/SysTenant/SysMessage/SysWorkflow*/SysFile 实体 · 仓储接口 · 领域异常
Application 应用层应用服务 · DTO · 权限校验 · 多租户过滤与工作流引擎 · 文件中心（FileAppService）· 审计留痕/清理
Infrastructure 基础设施层SqlSugar 仓储实现 · CodeFirst 建表 · 幂等种子数据（租户/工作流/消息/防护审计菜单）
Common 公共库JWT · Redis · SqlSugar 封装（租户过滤器）· 消息队列抽象（内存/RabbitMQ）· 幂等中间件 · 权限授权 · 统一返回 · SVG 验证码 · 登录锁定账本 · 存储抽象（本地盘/MinIO）
TaoAdmin.Utilities 工具库StringHelper · CryptoHelper · JsonHelper · DateTimeHelper · HttpHelper · ValidateHelper · TreeHelper

④ 中间件层
MySQL 8 :3306业务数据（含 sys_file 文件记录）· CodeFirst 自动迁移 · 种子数据（admin 账号）
MySQL 从库 ×N（可选）主从复制 · 只读查询分流（连接串配置 + 总开关）
MinIO（可选）内网 S3 兼容对象存储 · FileStorage:Provider=minio 切换 · 数据不出内网
Redis 7 :6379刷新令牌 · 服务心跳 · 分布式缓存
RabbitMQ :5672（可选，默认内存队列）消息持久化 · 断线重连 · 多实例投递 · 管理台 :15672
Nacos :8848（可选）服务注册发现 · 配置中心
Elasticsearch :9200（可选）分布式日志存储 · Kibana :5601 检索
⑤ 可观测性
链路追踪网关生成 TraceId → HTTP 头透传 → 各服务日志携带
日志双写Serilog → 本地文件（logs/）+ ES（可选）
服务监控中心页面可视化：健康状态 · 实例数 · 最近检查时间
⑥ 部署形态
本地开发dotnet run × 3 + npm run dev，中间件本机自装
Docker Compose 单机一键起 MySQL/Redis/Nacos/ES/网关/服务/前端
K8s / Jenkins / GitHub Actions镜像化部署 · 滚动更新 · CI/CD
